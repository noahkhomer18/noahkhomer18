# Noah Khomer

I work with brands in the ecommerce industry, mostly on ecommerce systems, paid ads, SEO, data
sync and data analysis. I've worked with a lot of them over the past decade, and I'm also a
programmer.

## Background

I started at twelve, pulling apart decoded `.swf` files from Flash games because there was a puzzle
I couldn't beat. I had no idea those files were programming language functions and operators. The
more I read them, the more I googled, and the more I learned.

## Education

I have a Master's in Computer Science and a Master's in Business Administration. I graduated magna
cum laude with minors in Software Engineering, Project Management, Web Design, Information Systems
and Data Analysis.

## Open source

I fully support open source. It helps people understand how enterprise systems work and how they're
built: what to look for, and the different bugs that turn up. Solving problems is the best part.

Because I work across such a wide domain, I don't get to write programs as much as I'd like. Whenever
I have the time, I jump on GitHub and contribute to projects I think are really needed.

## Stack

Python is where I am strongest. After that, ordered by how often I reach for it:

- **Languages** Python, TypeScript, JavaScript, Go, Java, SQL, PHP
- **Python** FastAPI, Flask, pandas, pytest, uv
- **Web** Next.js, React, Node.js, WordPress, Elementor, Tailwind
- **Data** PostgreSQL, MySQL, MongoDB, SQLite
- **Platforms** Odoo, Shopify, BigCommerce, WooCommerce, Klaviyo, Mailchimp, HubSpot
- **Environment** Docker, Git, GitHub Actions, Linux, PowerShell
